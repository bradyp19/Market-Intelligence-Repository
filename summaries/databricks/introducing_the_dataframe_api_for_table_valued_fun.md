Introducing the DataFrame API for Table-Valued Functions (, 2025-06-25)
Source: https://www.databricks.com/blog/introducing-dataframe-api-table-valued-functions
Summary: Table-Valued Functions (TVFs) have long been a powerful tool for processing structured data. They allow functions to return multiple rows and columns instead of just a single value. Previously, using TVFs in Apache Spark™ required SQL, making them less flexible for users who prefer the DataFrame API.
Key Features:
• . Users can now invoke TVFs directly within DataFrame operations, making transformations simpler, more composable, and fully integrated with Spark’s DataFrame workflow
